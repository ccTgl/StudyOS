# StudyOS v1.2.2 Public Beta 1

This directory contains the distribution documentation for the Windows x64 beta. The application is proprietary and distributed as a single-file EXE and a Portable ZIP.

The official Release page provides the build manifest, SHA-256 checksums and the approved licence as separate assets. The Portable ZIP includes the same licence.

The public release tag identifies this documentation commit. GitHub's automatic **Source code (zip)** and **Source code (tar.gz)** contain the public documentation and distribution materials. The complete application source and its exact source tag are held in the private source repository. The Release manifest distinguishes the binary source commit from this public documentation commit.
