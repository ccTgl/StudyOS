# StudyOS

StudyOS is a local-first Windows desktop workspace for course resources, PDF reading, notes, tasks, calendars, and focus sessions.

This repository hosts official beta downloads, documentation, and the public issue tracker. This is a binary-only beta. The full application source code is not included.

## Windows beta

Download the Portable ZIP and its SHA-256 checksum from [Releases](https://github.com/ccTgl/StudyOS/releases). StudyOS requires Windows x64 build 19041 or newer and includes the .NET runtime. The beta executable is unsigned. See the [installation guide](INSTALL.md) and [known issues](KNOWN_ISSUES.md) before trying it.
