# StudyOS v1.2.1 — Public Beta 1

- Row and column selections include the edge cells, including empty cells.
- Multiple editable tables can be saved in one note, restored from backup, and included in PDF + Notes export.
- Workspace restore rebases managed paths when restoring into a different workspace. Manual backup saves pending edits from separate note windows.

This beta provides a self-contained, unsigned Windows x64 Portable ZIP. See [Installation](INSTALL.md), [Known issues](KNOWN_ISSUES.md), and [Privacy](PRIVACY.md).
