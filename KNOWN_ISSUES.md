# Known issues

- **Unsigned Windows build.** Windows x64 is the only supported platform. Compatibility on a clean Windows image and SmartScreen behavior after downloading from the official Release remain pending.
- **Setup EXE is withheld.** Microsoft Defender flagged an uninstaller generated by an earlier Inno Setup test as `Trojan:Win32/Bearfoos.A!ml`. That classification awaits review. The Portable ZIP and its executable are separate artifacts.
- **Input coverage.** WPF table menus, selection, and routed Undo/Redo passed automated checks. Physical right-click and keyboard shortcut acceptance remain pending.
- **Provider integrations.** Gmail and calendar integration depend on OAuth client configuration and provider authorization. Hosted cloud sync and a macOS build are unavailable in this beta.
- **Restore edge cases.** Power loss during final SQLite commit and a physically full destination disk are unverified.
